# CRM CNA Roma

App di consultazione imprese associate CNA Roma.

## Funzionalità
- Login con le stesse credenziali dell'ERP CNA
- Ricerca imprese per Ragione Sociale, P.IVA, Titolare, Comune, CF
- Scheda anagrafica completa a pagina intera (ottimizzata mobile)
- Dati Anagrafici, Addetti, Stato Associativo, Contratti, Mappa

## Stack
- HTML/CSS/JS vanilla — zero dipendenze
- Supabase (stesso progetto dell'ERP Dashboard)
- Autenticazione via Edge Function `cna-login`

## Deploy
Deployato su Vercel: collegato a questo repo, build automatica su push.
